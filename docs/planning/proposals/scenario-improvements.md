# YHAI 서비스 시나리오 개선 제안서

> 작성일: 2026-03-12
> 작성자: 서비스 플랜 전문가
> 기반 자료: 경쟁사 분석 리포트 + 에이전트 UX 패턴 조사

---

## 개선 방향 요약

경쟁사 분석과 최신 UX 트렌드를 바탕으로, YHAI의 5개 핵심 시나리오에 대해 **차별화된 사용자 경험**을 제안합니다.

핵심 원칙:
1. **프롬프트 의존 탈피** — 전문가 대화로 요구사항을 자연스럽게 구체화 (경쟁사의 "70% 문제" 해결)
2. **투명한 빌드 과정** — 블랙박스가 아닌, 에이전트팀 작업 과정 실시간 시각화
3. **능동적 AI** — 전문가가 먼저 질문하고 누락 사항을 제안하는 선제적 경험
4. **점진적 정교화** — 한 번에 완벽한 프롬프트가 아닌, 대화를 통한 반복적 개선

## 시나리오별 개선안

### 시나리오 1: 온보딩 → 첫 프로젝트 생성 → 전문가 대화

#### 기존 마스터 플랜
```
신규 사용자 → 회원가입 → 프로젝트 생성 → 전문가 자동 추천 → 대화 → 요구사항 확정
```

#### 개선안

**A. 인텐트 기반 온보딩 (경쟁사 대비 차별화)**
```
1. 회원가입 직후 — "어떤 것을 만들고 싶으세요?" (자유 입력)
2. 인텐트 분석 — AI가 사용자 의도를 빠르게 분류
3. 유사 사례 카드 제시 — "이런 서비스를 만드시려는 건가요?"
   - 3-5개 유사 앱 카드 (스크린샷 + 한줄 설명)
   - 사용자가 카드 선택/조합하면 초기 컨텍스트 강화
4. 전문가 자동 추천 카드 — 도메인에 맞는 전문가 2-3명 추천
   - 각 전문가의 전문 분야, 어떤 질문을 도와줄 수 있는지 미리보기
5. 대화 시작 — 첫 번째 전문가가 능동적으로 인사 + 핵심 질문 3개 제시
```

**B. 가이디드 퍼스트 대화 (초보자 UX 개선)**
- 전문가가 **구조화된 질문 흐름**으로 안내 (목적 → 타겟 사용자 → 핵심 기능 → 비즈니스 모델)
- 각 질문에 **예시 답변 칩** 제공 (원클릭 선택 가능)
- 진행률 표시바: "요구사항 정의 40% 완료"
- 이 과정이 Lovable/Bolt의 "프롬프트 한 줄로 시작" 대비 **질적으로 우수한 결과물** 보장

### 시나리오 2: 전문가 추가 초빙 → 전문 영역 보완

#### 기존 마스터 플랜
```
대화 중 추가 전문가 직접 초빙 → 전문 영역 질문/조언 → 요구사항 보완
```

#### 개선안

**A. 컨텍스트 감지 자동 추천 (능동적 에이전트)**
```
1. 대화 중 결제 관련 언급 감지
2. 시스템이 대화 흐름에 자연스럽게 추천 카드 삽입:
   "💡 결제 시스템에 대해 더 깊은 논의가 필요해 보입니다.
    결제/핀테크 전문가를 초대할까요?"
3. 사용자 수락 → 전문가 자연스럽게 대화 합류
   "안녕하세요! 지금까지 대화를 검토했습니다.
    PG 결제 방식으로 3가지 옵션이 있는데, 설명드릴까요?"
```

**B. 전문가 핸드오프 패턴**
- 새 전문가 합류 시 **이전 대화 요약을 자동 학습** (사용자가 같은 말 반복 안 함)
- 전문가별 대화 영역이 **시각적으로 구분** (배경색, 아바타, 전문 분야 태그)
- 전문가 간 **크로스 레퍼런스**: "이커머스 전문가가 말한 상품 구조를 고려하면..."

**C. 전문가 갤러리 (수동 초빙 UX)**
- "+" 버튼 클릭 시 전문가 갤러리 표시
- 각 전문가 카드: 아바타, 이름, 전문 분야, "이 전문가가 도울 수 있는 것" 3가지
- 현재 대화 컨텍스트 기반으로 **추천 순서 정렬**

### 시나리오 3: 요구사항 확정 → AI 개발팀 빌드

#### 기존 마스터 플랜
```
요구사항 확정 → 팀 자동 생성 → 빌드 진행 관찰 → 결과물 확인
```

#### 개선안

**A. 요구사항 대시보드 (확정 전 리뷰)**
```
1. 대화 종료 → AI가 자동으로 요구사항 카드 생성
   - 기능 요구사항 (카테고리별 그룹핑)
   - 비기능 요구사항 (성능, 보안, 접근성)
   - 우선순위 자동 부여 (전문가 대화 맥락 기반)
2. 사용자가 카드를 드래그&드롭으로 우선순위 조정
3. 각 카드에 "왜 이 기능이 필요한지" AI 근거 표시
4. "✅ 확정" 버튼 → 빌드 단계 진입
```

**B. 팀 빌딩 시각화 (투명성)**
```
1. "팀을 구성하고 있습니다..." 애니메이션
2. 에이전트 카드가 하나씩 등장:
   - 🎨 UI/UX 디자이너 — "디자인 시스템을 설계합니다"
   - 💻 프론트엔드 개발자 — "React 컴포넌트를 구현합니다"
   - ⚙️ 백엔드 개발자 — "API와 데이터 모델을 구축합니다"
   - 🗄️ DB 아키텍트 — "데이터 구조를 최적화합니다"
3. 태스크 분해 시각화 — 각 에이전트에게 할당된 작업 트리
4. 의존성 그래프 표시 — 어떤 작업이 어떤 작업을 기다리는지
```

**C. 빌드 진행 대시보드 (Mission Control)**
- **실시간 진행률**: 전체 + 에이전트별 진행률 바
- **라이브 로그**: 각 에이전트가 현재 무엇을 하고 있는지 스트리밍
- **파일 트리 실시간 업데이트**: 생성되는 파일이 하나씩 나타남
- **예상 완료 시간**: AI 기반 ETA 표시
- Bolt.new의 "브라우저 내 실시간 실행" + Lovable의 "자율 빌드"의 장점 결합

### 시나리오 4: 결과물 미리보기 → 수정 → 재빌드 → 배포

#### 기존 마스터 플랜
```
결과물 미리보기 → 수정 요청 → 재빌드 → 배포
```

#### 개선안

**A. 3-패널 미리보기 (코드 + 프리뷰 + 대화)**
```
┌─────────────┬─────────────┬──────────────┐
│  파일 트리   │  라이브 프리뷰  │   수정 대화    │
│  + 코드 뷰어  │  (반응형 전환)  │  (전문가 대화)  │
│             │             │              │
│ 파일 클릭 →   │ ← 실시간 반영  │ "헤더 색상을    │
│ 코드 하이라이트│             │  파란색으로"    │
└─────────────┴─────────────┴──────────────┘
```

**B. 포인트 앤 토크 수정 (v0 Design Mode 개선)**
- 프리뷰에서 요소 클릭 → 해당 요소에 대한 수정 대화 시작
- "이 버튼의 색상을 바꿔주세요" → AI가 해당 컴포넌트만 수정
- **부분 재빌드**: 전체가 아닌 변경된 컴포넌트만 재생성 (경쟁사 대비 차별화)

**C. 배포 파이프라인 시각화**
```
빌드 완료 → 테스트 자동 실행 → 스테이징 배포 → 사용자 승인 → 프로덕션 배포
              ↑                                    ↑
         자동 (AI 수행)                      Human-in-the-Loop
```
- 각 단계에 체크마크 애니메이션
- 배포 URL 즉시 제공 + QR 코드 (모바일 테스트)

---

### 시나리오 5: 프로젝트 재방문 → 이어가기

#### 기존 마스터 플랜
```
기존 프로젝트 재방문 → 대화 이어가기 → 추가 기능 요청
```

#### 개선안

**A. 프로젝트 히스토리 대시보드**
```
대시보드
├── 진행 중 프로젝트
│   ├── 🟢 쇼핑몰 앱 — 빌드 완료, 배포됨
│   ├── 🟡 블로그 플랫폼 — 요구사항 정의 중
│   └── 🔴 예약 시스템 — 수정 대기 중
└── 완료된 프로젝트 아카이브
```

**B. 컨텍스트 복원 대화 (능동적 에이전트)**
- 재방문 시 전문가가 이전 대화 요약 제시:
  "지난번에 쇼핑몰의 결제 기능까지 논의했습니다.
   오늘은 배송 추적 기능을 추가하시겠어요?"
- 이전 요구사항 카드 자동 로드
- **변경 영향 분석**: "배송 기능 추가 시, 기존 주문 모델에 3개 필드가 추가됩니다"

**C. 버전 관리 및 롤백**
- 빌드 히스토리 타임라인 표시
- 이전 버전으로 롤백 가능
- 각 버전의 변경사항 diff 뷰

## 전문가 초빙 시나리오 상세

### 자동 감지 흐름
```
사용자 메시지 입력
      ↓
[Haiku 분류기] 도메인 키워드 + 의도 분석
      ↓
신뢰도 80% 이상 → 추천 카드 표시
신뢰도 50-80% → 부드러운 제안 ("혹시 ~에 대해 전문가 도움이 필요하신가요?")
신뢰도 50% 미만 → 추천하지 않음
      ↓
사용자 수락 → 전문가 합류 (이전 대화 요약 자동 학습)
사용자 거부 → "나중에 다시 추천" 옵션
```

### 수동 추가 흐름
```
사용자가 "+" 버튼 클릭
      ↓
전문가 갤러리 표시 (현재 대화 컨텍스트 기반 추천순 정렬)
      ↓
카드 선택 → 전문가 소개 팝오버 (전문 분야, 도움 가능 영역)
      ↓
"초대하기" 클릭 → 전문가 합류
```

### 전문가 퇴장 흐름
```
사이드 패널에서 전문가 카드의 "×" 버튼
      ↓
"정말 퇴장시키시겠어요? 이 전문가의 기여 내용은 유지됩니다."
      ↓
확인 → 전문가 퇴장 (기여 내용은 대화 히스토리에 보존)
      ↓
나중에 같은 전문가 재초빙 가능 (이전 기여 기억)
```
