# AI 에이전트 UX 패턴 조사 리포트

> 조사일: 2026-03-12
> 조사자: 웹 검색 전문가

---

## 1. 멀티 에이전트 대화 UI 패턴

### 1.1 대화형 인터페이스 패턴 (CIP)
- 단순 챗봇을 넘어 **에이전트 주도적, 멀티모달 경험**으로 진화
- 메시지 스레딩, 컨텍스트 보존, 리치 콘텐츠 표시
- 능동적 에이전트 상호작용 + 다중 커뮤니케이션 채널 + 컨텍스트 인식

### 1.2 멀티모달 인터랙션
- 음성, 시각, 제스처, 텍스트 통합
- 컨텍스트에 따른 자동 모달리티 선택
- 다양한 진입점: 챗봇, 폼, 파일 업로드, 특정 에이전트와 직접 대화

### 1.3 에이전트 상태 시각화
- 실시간 에이전트 활동, 사고 상태, 운영 상태 표시
- 신뢰도 시각화: AI 확신 수준, 불확실성 범위 시각적 표시
- 시각적 추론 인터페이스: 에이전트 의사결정과 추론 과정 투명하게 표시

---

## 2. 사용자-에이전트 인터랙션 모델

### 2.1 Human-in-the-Loop (HITL)
- 핵심 결정 지점에서 인간 판단 통합
- YHAI 적용: 요구사항 확정, 빌드 시작, 배포 승인 등에 적용

### 2.2 Human-on-the-Loop (HOTL)
- 감독적 모니터링 + 실시간 개입 가능
- YHAI 적용: 빌드 진행 중 실시간 모니터링, 필요 시 중단/수정

### 2.3 Mixed-Initiative 인터페이스
- 인간과 에이전트 간 **매끄러운 제어권 전환**
- 협업적 문제 해결 가능
- YHAI 적용: 전문가 대화 중 사용자가 주도하거나 전문가가 주도하는 흐름 자연 전환

---

## 3. 신뢰 및 투명성 패턴

### 3.1 Microsoft 에이전트 UX 원칙
- 에이전트의 지식, 도구/스킬, 연결이 **투명하고 커스터마이징 가능**해야 함
- 에이전트 상태 항상 가시적
- 추천 이유에 대한 명확한 가시성
- 백그라운드 프로세스 로그/대시보드로 가시화

### 3.2 사용자 제어 메커니즘
- 에이전트 활성화 on/off 토글
- 방해 금지(DND) 설정
- 인터랙션 모달리티 커스터마이징 (음성 vs 텍스트)
- 자동화 동작에 대한 접근 가능한 설정 인터페이스

### 3.3 프로그레시브 디스클로저
- 에이전트 역량과 복잡한 추론을 **점진적으로 공개**
- 인지 과부하 방지
- YHAI 적용: 초보 사용자에게는 간단한 흐름, 숙련자에게는 상세 컨트롤 노출

---

## 4. 2026년 핵심 트렌드

### 4.1 능동적/예측적 에이전트
- 반응적 → **능동적** AI로 전환 (2026년 핵심 트렌드)
- 장기 메모리 기반 사용자 니즈 예측
- "알림보다 넛지" — 동적 컨텍스트 큐 생성, 능동적 대화 시작

### 4.2 초개인화
- 사용자 행동, 선호도, 감정 상태 기반 실시간 인터페이스 적응
- 경계 트리거 능동적 개입: 52% 참여율 + 제안 해석 시간 50% 단축

### 4.3 신뢰 중심 설계
- 2026년은 **신뢰, 안전, 설명 가능성** 중심
- 시장 리더 = 가장 이해하기 쉽고, 예측 가능하며, 사용자 통제 하에 있는 AI

### 4.4 대화형 AI 인터페이스 보편화
- 2025년 기준 81%의 새 전문가 시스템이 대화형 AI 인터페이스 도입
- LLM 기반 자연어 인터페이스가 표준

## 5. YHAI 설계 시사점

| 패턴 | YHAI 적용 방안 |
|------|---------------|
| 멀티 에이전트 UI | 전문가별 아바타/이름/색상 구분 + 사이드 패널 참여 목록 |
| 에이전트 상태 표시 | 전문가 "생각 중" 상태, 빌드 에이전트 작업 진행률 실시간 표시 |
| HITL | 요구사항 확정, 팀 구성 승인, 배포 승인에 체크포인트 |
| 프로그레시브 디스클로저 | 초보자에겐 간단한 대화, 전문가에겐 상세 설정 노출 |
| 능동적 에이전트 | 전문가가 먼저 질문하고, 누락된 요구사항을 제안 |
| 신뢰/투명성 | 전문가 추천 이유 표시, 빌드 과정 로그 공개 |
