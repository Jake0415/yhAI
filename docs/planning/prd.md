## 1. 제품 개요

### 1.1 비전

> 창업을 꿈꾸는 누구나, AI 전문가 팀과 대화하며 아이디어부터 사업 실행까지 원스톱으로 준비할 수 있는 세상

### 1.2 미션

예비 창업자가 창업 아이템을 입력하면 AI 전문가 팀(창업전략, 법률, 세무, 상권, 마케팅, 자금)이 단계적으로 가이드하여, 아이디어 검증부터 사업계획서 작성, 법률/세무 참고 자문, 상권분석, 마케팅 전략, 자금조달 가이드까지 한국 시장에 특화된 종합 창업 지원을 제공한다. 웹서비스가 필요한 경우 MVP 자동 구축도 선택적으로 지원한다.

### 1.3 핵심 가치 제안 (Value Proposition)

| 가치 | 설명 |
|------|------|
| **6개 분야 원스톱 통합** | 창업전략, 법률, 세무, 상권, 마케팅, 자금 - 파편화된 창업 준비를 하나의 플랫폼에서 해결 |
| **AI 전문가 팀 경험** | 단일 챗봇이 아닌, 역할별 전문가가 자신의 도메인에서 맞춤 질문과 조언을 제공하는 구조화된 대화 |
| **한국 시장 특화** | 한국 법률, 세법, 상권 데이터, 정부 지원사업 정보를 반영한 실질적 가이드 |
| **단계적 창업 여정 가이드** | 아이디어 검증 -> 사업계획 -> 법률/세무 확인 -> 상권분석 -> 마케팅 -> 자금조달 순서로 체계적 진행 |
| **선택적 MVP 자동 구축** | IT 서비스 창업 시 대화만으로 웹서비스 MVP를 자동 생성하여 배포까지 지원 |

### 1.4 타겟 사용자

| 페르소나 | 핵심 니즈 | YHAI 솔루션 |
|---------|----------|------------|
| **예비 소상공인** (식당, 카페, 학원, 치킨집 등) | 업종별 창업 절차, 인허가, 상권, 초기 비용을 체계적으로 파악하고 싶음 | 업종 특화 전문가 가이드 + 상권분석 + 세무/법률 참고 자문 |
| **1인 창업 기획자** (IT 서비스, 쇼핑몰, 플랫폼 등) | 아이디어를 검증하고 사업계획서를 작성한 뒤, 빠르게 MVP를 만들고 싶음 | Lean Canvas 가이드 + 사업계획서 자동 생성 + MVP 웹서비스 빌드 |
| **프랜차이즈 예비 가맹점주** | 가맹 비용 분석, 상권 적합도, 예상 수익성을 사전에 검토하고 싶음 | 프랜차이즈 분석 전문가 + 상권/재무 시뮬레이션 |
| **경력 전환 창업자** (퇴직 후 창업, 부업 등) | 자금 규모에 맞는 창업 아이템 추천과 리스크 최소화 가이드가 필요함 | 자금 전문가 + 창업 전략가 + 정부 지원사업 매칭 |

### 1.5 경쟁 포지셔닝

```
         전문성 높음
              |
   SSEM(세무) |  YHAI ★
   LBox(법률) |  (종합+전문+한국특화)
              |
단일기능 -----+------ 종합 통합
              |
   상권분석   |  ChatGPT
   LivePlan   |  (종합+범용)
              |
         전문성 낮음
```

**YHAI 차별화 포지션**: 높은 전문성 + 종합 통합 + 한국 시장 특화

| 경쟁자 유형 | 대표 서비스 | YHAI 차별점 |
|------------|-----------|-----------|
| **공공 포털** | K-Startup, 소상공인마당 | 정보 나열 vs AI 맞춤 대화형 가이드, 보완적 관계 |
| **상권분석 도구** | 소상공인 상권정보시스템, 오픈업 | 데이터 시각화 vs AI 해석 + 종합 가이드 통합 |
| **해외 비즈플랜** | LivePlan, Bizplan, Upmetrics | 미국 특화/사업계획서 전용 vs 한국 법률/세무/상권 통합 |
| **세무/법률 AI** | SSEM, LBox | 단일 분야 특화 vs 6개 분야 원스톱 |
| **범용 AI** | ChatGPT, Claude, Gemini | 비체계적/할루시네이션 vs 전문 데이터 + 단계적 프로세스 |
| **웹빌더 AI** | Bolt.new, Lovable, v0 | 코드 생성 전용 vs 창업 기획 + 선택적 빌드 |

## 2. 기능 요구사항 (MoSCoW 분류)

### 2.1 Must Have -- MVP (최소 기능 제품)

> MVP 목표: 예비 창업자가 아이템을 입력하면 AI 전문가 팀(창업전략 + 마케팅)이 사업계획서를 자동 생성하고, 핵심 3개 분야(창업전략, 사업계획서, 마케팅)의 가이드를 받을 수 있는 end-to-end 흐름 완성
> MVP 핵심 분야: 창업전략 + 사업계획서 자동 생성 + 마케팅 전략

#### F-M01: 회원가입/로그인

| 항목 | 내용 |
|------|------|
| **설명** | Supabase Auth 기반 소셜 OAuth(Google, Kakao) + 이메일/비밀번호 인증 |
| **수용 기준** | - 소셜 로그인 2종(Google, Kakao) 동작 / - 이메일 회원가입 + 이메일 인증 / - JWT 토큰 자동 갱신 / - 로그인 상태 유지 (세션 관리) |
| **관련 화면** | A1 로그인, A2 회원가입, A3 OAuth 콜백 |
| **API** | `POST /auth/signup`, `POST /auth/login`, `GET /auth/callback`, `GET /auth/me` |

#### F-M02: 창업 프로젝트 생성 (아이템 입력)

| 항목 | 내용 |
|------|------|
| **설명** | 사용자가 창업 아이템(치킨집, 카페, IT서비스 등)을 입력하면 AI가 업종을 분석하여 프로젝트 생성 + 관련 전문가 자동 추천 |
| **수용 기준** | - 자유 텍스트로 창업 아이템 입력 / - 업종 카테고리 자동 분류 (외식, 교육, IT, 유통, 서비스업 등) / - "아이디어가 없으신가요?" 탐색 모드 진입점 제공 / - 프로젝트 상태 `CONSULTING`으로 시작 |
| **관련 화면** | D2 새 프로젝트 생성 |
| **API** | `POST /api/projects` |

#### F-M03: AI 전문가 자동 추천 + 초빙

| 항목 | 내용 |
|------|------|
| **설명** | 사용자의 창업 아이템/대화 내용을 분석하여 적합한 AI 전문가를 자동 추천. 사용자가 수락/거부 선택 |
| **수용 기준** | - 아이템 기반 전문가 2~3명 자동 추천 (항상 창업전략가 포함) / - 추천 카드 UI(수락/거부 버튼) / - 수락 시 전문가가 대화에 참여 / - 사용자가 직접 전문가 추가/제거 가능 / - 대화 중 필요한 전문가 동적 추천 |
| **관련 화면** | PJ1 채팅 (사이드 패널) |
| **API** | `GET /api/experts/recommend`, `POST /api/projects/:id/experts`, `DELETE /api/projects/:id/experts/:expertId` |

**AI 전문가 팀 구성 (MVP 기준)**:

| 전문가 | 도메인 | 역할 | 아바타 색상 | MVP 포함 |
|--------|--------|------|-----------|---------|
| **창업 전략가** | startup-strategy | 아이디어 검증, 비즈니스 모델 설계, 경쟁분석, 타겟 고객 정의 | 보라색 | O |
| **마케팅 전문가** | marketing | 마케팅 전략, 브랜딩, 고객 획득 채널, SNS 전략, 콘텐츠 마케팅 | 주황색 | O |
| **법률 전문가** | legal | 사업자등록, 인허가, 계약서, 근로기준법, 프랜차이즈법 (참고 자문) | 남색 | X (V1) |
| **세무 전문가** | tax | 세금 종류, 절세 전략, 간이/일반 과세, 부가세, 종소세 (참고 자문) | 초록색 | X (V1) |
| **상권분석가** | location-analysis | 상권 데이터 분석, 입지 선정, 경쟁업체 분석, 유동인구 | 파란색 | X (V1) |
| **자금 전문가** | funding | 자금조달, 정부 지원사업, 대출, 투자유치, 재무계획 | 금색 | X (V2) |
| **IT 전문가** | web-build | 웹서비스 MVP 자동 구축 (기존 YHAI 빌드 시스템 연계) | 회색 | X (V2) |

### 2.2 Should Have -- V1 (첫 정식 릴리스)

> V1 목표: 법률/세무/상권 전문가 추가 + Lean Canvas + 재무 시뮬레이션으로 6개 분야 중 5개 커버

#### F-S01: 법률 전문가 (참고 자문)

| 항목 | 내용 |
|------|------|
| **설명** | 사업자등록, 인허가, 업종별 규제, 프랜차이즈법, 근로기준법 등 창업 관련 법률 참고 자문을 제공하는 AI 전문가 |

#### F-S02: 세무 전문가 (참고 자문)

| 항목 | 내용 |

### 6.2 프로젝트 상태 머신

```
IDEA_EXPLORING -> CONSULTING -> BIZ_MODEL_DESIGN -> BP_GENERATING
    (선택)                          (선택)              |
                                                        v
                                                  BP_COMPLETE -> DETAILED_REVIEW
                                                                      |
                                                                      v
                                                                  COMPLETED
                                                                      |
                                                                      v
                                                                  ARCHIVED
```

**상태 설명**:
- `IDEA_EXPLORING`: 아이디어 탐색 중 (선택적 진입점)
- `CONSULTING`: 전문가 채팅 진행 중 (메인 상태)
- `BIZ_MODEL_DESIGN`: Lean Canvas 작성 중 (선택적)
- `BP_GENERATING`: 사업계획서 생성 중
- `BP_COMPLETE`: 사업계획서 완성
- `DETAILED_REVIEW`: 법률/세무/상권/자금 상세 검토
- `COMPLETED`: 창업 준비 완료
- `ARCHIVED`: 아카이브

## 부록 A: AI 전문가 시스템 프롬프트 설계 원칙

### 공통 원칙

1. **능동적 질문**: 사용자 질문에만 답하지 않고, 빠진 정보를 선제적으로 질문
2. **구체화 유도**: 모호한 답변에는 반드시 구체적 예시와 함께 재질문
3. **예시 칩 제공**: 모든 질문에 2~3개 빠른 응답 예시 칩 함께 제시
4. **크로스 레퍼런스**: 다른 전문가가 제시한 내용을 참조하여 통합적 관점 제공
5. **한국 시장 기준**: 모든 자문은 한국 법률, 세법, 시장 환경 기준

### 면책 설계 원칙 (법률/세무/자금 전문가)

1. 모든 응답 하단에 면책 배너 자동 삽입
2. 첫 대화 시 면책 동의 팝업 표시 + 동의 타임스탬프 기록
3. 확정적 표현 금지 ("~해야 합니다" -> "~하는 것이 일반적입니다", "~를 검토해보세요")
4. 전문가 연계 CTA 항상 노출 ("더 정확한 확인이 필요하시면 전문가 상담을 추천드립니다")
